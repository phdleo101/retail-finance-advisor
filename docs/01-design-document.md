# 零售金融智能顾问 — FDE 方案设计文档

## 项目概述

**项目名称**：零售金融智能顾问（Retail Finance AI Advisor）
**行业**：零售金融
**定位**：基于风险测评的智能理财产品推荐与资产配置系统
**FDE作品集**：项目三（能源/医疗/金融 三行业全覆盖）

## FDE 五步方法论应用

### 1. 行业速学

**调研内容**：
- 2025年被称为金融智能体"交付元年"，60%头部金融机构计划将AI嵌入核心业务
- 多家银行推出AI财富智能体：浦发银行"浦小财"、浙商银行"浙里智能投研顾问"
- 贵阳银行用 DeepSeek + 标准普尔模型做资产配置
- 消费金融公司大模型应用：蚂蚁（交互式自证）、杭银（信用大脑风控）

**关键数据**：
- 居民消费性贷款余额 21.29 万亿元
- 持牌消费金融公司贷款余额 1.35 万亿元
- 信用卡在用卡量 7.15 亿张
- 30%用户抱怨转人工客服慢、反复循环
- 超半数客户办理业务后感到过度营销

### 2. 痛点定位

| 痛点 | 现状 | AI可创造价值 |
|---|---|---|
| 产品推荐"千人一面" | 不考虑客户风险偏好，统一推荐 | 个性化风险等级匹配 |
| 风险测评枯燥 | 传统问卷长且无聊，客户随便填 | 交互式10题快速测评+可视化 |
| 理财知识匮乏 | 70%受访者难以及时获取专业分析 | RAG智能问答7×24h在线 |
| 资产配置不科学 | 凭感觉分配，缺乏系统方法论 | 标准普尔四象限可视化配置 |

### 3. 方案设计

**技术架构**：
- 前端：Streamlit（4个Tab）
- 逻辑层：Python（风险评分+产品匹配+标普模型）
- RAG引擎：Dify Cloud（流式SSE）
- 可视化：Plotly（饼图/柱状图/雷达图）
- 部署：Streamlit Community Cloud + GitHub

**核心功能**：
1. 风险测评：10题问卷 → C1-C5五级评分 → 各维度可视化
2. 产品推荐：风险等级匹配 → 50款产品筛选 → 多维度排序
3. 智能问答：Dify RAG流式 → 金融知识库 → 本地降级
4. 资产配置：标普四象限 → 投资金额分配 → 组合详情

### 4. AI驱动构建

| 组件 | 工具 | 说明 |
|---|---|---|
| 前端 | Streamlit | Python Web框架，快速构建数据应用 |
| RAG | Dify Cloud | 知识库+流式API（复用项目一架构） |
| 可视化 | Plotly | 交互式图表（饼图/柱状图） |
| 数据 | JSON | 50款产品+10题问卷+知识库 |
| 部署 | Streamlit Cloud | 免费托管，GitHub自动CI/CD |

### 5. 部署验证

- GitHub代码仓库
- Streamlit Cloud在线Demo
- Dify Cloud RAG引擎

## 合规设计

- 投资者适当性管理：C1-C5只能购买对应风险等级及以下产品
- 免责声明：不构成投资建议，仅提供参考
- 资管新规：禁止刚兑，净值化转型
- 存款保险：50万以内全额保障
